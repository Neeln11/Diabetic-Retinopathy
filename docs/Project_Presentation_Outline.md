## ⚠️ Slide 2: The Clinical Problem
- **Context**: 500M+ Diabetics globally; blindness is preventable if caught early.
- **Challenge**:
    - **Screening Gap**: Too few ophthalmologists to screen everyone.
    - **AI Trust**: Black-box models are brittle (Domain Shift) and often overconfident.
    - **Goal**: Build a "Safety-First" screening aid that doctors can trust and teach.

## 🛠️ Slide 3: Engineering The Solution
- **Architecture**: Swin-Tiny (Hierarchical Vision Transformer).
    - *Why?* Models long-range retinal features (vessels/lesions) better than localized CNNs.
    - *Constraint*: Optimized for consumer hardware (4GB VRAM) using Gradient Checkpointing, Mixed Precision (FP16), and Ordinal Regression Head.
- **Innovation**: **Ordinal Regression Loss**.
    - Treated disease grades (0-4) as an ordered sequence, not independent classes.
    - Result: 2x penalty for missing "Referable" cases (Sensitivity Boost).

## 📉 Slide 4: Overcoming "Reality Gap" (Domain Shift)
- **The Fail**: Initial model (trained on DDR/China) failed on Messidor-2 (France) -> QWK 0.21.
- **The Fix**:
    1.  **Preprocessing**: Enforced Ben Graham Color Normalization.
    2.  **Adaptation**: Few-Shot fine-tuning on just 200 Messidor images.
    3.  **Result**: Accuracy +6%, Sensitivity -> 96.4%.

## 🤝 Slide 5: The Human-in-the-Loop (HITL) Workflow
- **Workflow**:
    1.  AI Grades Image.
    2.  Doctor corrects AI on Dashboard.
    3.  System retrains adaptively.
- **Impact**: Reduced "Critical Misses" from **25%** to **3.6%**.
- **Visual**: Comparison Chart (`hitl_progress_chart.png`).
